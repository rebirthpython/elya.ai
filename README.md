# Эля — персональный ИИ-ассистент в Telegram

Ассистент для одного пользователя: естественный диалог на русском от лица Эли с учётом
контекста. Общаться можно двумя способами, память у них общая:

- **Mini App** — HTML5-приложение внутри Telegram с собственным интерфейсом: лента
  сообщений, оформление ответов (списки, код, таблицы), выбор модели, тёмная и светлая темы.
- **Чат с ботом** — обычные сообщения, как раньше.

Отвечают бесплатные языковые модели (Gemini, OpenRouter, Groq, Mistral) с автоматическим
переключением между ними. История сохраняется между перезапусками, доступ только
по Telegram ID.

**Текущий статус: этап 1 (MVP) + Mini App.** Работают: Mini App, `/start`, `/help`, `/clear`,
`/cancel`, диалог с ИИ, история в SQLite, ограничение доступа, лимиты запросов, фолбэк между
моделями и провайдерами, индикатор «печатает…», разбиение длинных ответов.

## AI-провайдер

Бот работает с любым **OpenAI-совместимым** API (`POST /chat/completions`) через HTTPX,
без SDK конкретных компаний. Провайдеры перечисляются в `AI_PROVIDERS` в порядке приоритета:
если модель упёрлась в лимит или недоступна, бот пробует следующую модель или провайдера.

| Провайдер | Роль | Бесплатный доступ (проверь перед запуском) |
|---|---|---|
| **Google Gemini API** | основной | Бесплатный тариф AI Studio без привязки карты, но только для моделей Flash / Flash-Lite. Лимиты считаются на проект и периодически меняются: [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits) |
| OpenRouter | резерв | Модели с суффиксом `:free`: около 20 запросов в минуту и 50 в сутки, после разовой покупки кредитов на $10 — 1000 в сутки. Неудачные запросы тоже расходуют лимит: [limits](https://openrouter.ai/docs/api-reference/limits) |
| Groq | опционально | Бесплатный тариф с лимитами на модель: [rate limits](https://console.groq.com/docs/rate-limits). Ключ и модели — `GROQ_*` |
| Mistral AI | опционально | Бесплатный план Experiment, по умолчанию `mistral-small-latest`; запросы могут использоваться для обучения моделей. Ключ — `MISTRAL_API_KEY` |
| Ollama и другие | опционально | Любой OpenAI-совместимый сервер: `CUSTOM_*` в `.env` |

Чем больше провайдеров подключено, тем реже Эля упирается в лимиты: провайдеры без ключа
просто пропускаются. В `OPENROUTER_MODELS` последним стоит `openrouter/free` — роутер, который
сам выбирает одну из доступных бесплатных моделей, если конкретную убрали из каталога.

⚠️ Важно:
- **Регион.** Gemini API доступен не во всех странах, в частности не в РФ. Это касается
  страны, где запущен *сервер бота*, а не страны пользователя. Если сервер в неподдерживаемой
  стране, бот запишет в лог ошибку региона и переключится на резервного провайдера.
- **Приватность.** На бесплатных тарифах провайдеры могут использовать запросы для улучшения
  моделей. Бот предупреждает об этом в `/start`, приложение — в настройках.

## Быстрый старт

Нужен Python 3.12+.

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Получи ключ Gemini: <https://aistudio.google.com/apikey>. Можно дополнительно получить
   резервный ключ OpenRouter: <https://openrouter.ai/keys>.
4. Установи и запусти бота:

```bash
cd elya.ai
python3.12 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # заполни BOT_TOKEN, ALLOWED_USER_IDS, GEMINI_API_KEY
python main.py
```

Если всё в порядке, в логе появится строка `Bot @имя_бота started. Providers: gemini[...]`.
На этом шаге уже работает чат с ботом; приложение включается отдельно — см. следующий раздел.

## Фото

Пришли боту фото (можно с подписью-вопросом: «что это за цветок?», «переведи текст на
скриншоте») — Эля посмотрит и ответит. Картинку, отправленную файлом, тоже понимает (до 5 МБ).
В приложении — скрепка 📎 в поле ввода: выбери фото, добавь подпись и отправь. Телефон сам
уменьшает фото до 1600 px перед отправкой — так быстрее и стираются служебные данные снимка.

- Фото уходит только моделям, которые умеют смотреть картинки (`<ИМЯ>_VISION_MODELS`, см.
  `.env.example`). Модели Gemini умеют по умолчанию. Если таких моделей нет, Эля об этом скажет,
  а скрепки в приложении не будет.
- В истории диалога сохраняется пометка «📷 Фото: подпись» и ответ Эли, сама картинка — нет.

## Голосовые сообщения

Отправь боту голосовое: Эля покажет, что расслышала («🎤 …»), и ответит как на обычный текст.
В приложении — кнопка микрофона в поле ввода (появляется, когда поле пустое): нажми, говори,
нажми ➤ — распознанный текст уйдёт как обычное сообщение; ✕ отменяет запись. Если Telegram не даёт
приложению доступ к микрофону, кнопка подскажет отправить голосовое прямо в чат с ботом.
Распознаёт Groq Whisper (бесплатный тариф, без карты): достаточно указать `GROQ_API_KEY` в `.env`,
даже если Groq не используется как модель для ответов. Голосовые до 5 минут.

## Напоминания

Эля присылает напоминание сообщением в Telegram в нужное время.

- **Как поставить.** Напиши обычной фразой: «напомни завтра в 9 позвонить маме», «напомни через
  2 часа проверить пирог», «напоминай каждый день в 8:30 пить воду», «напомни в пятницу…».
  Повторы: каждый день, по будням, каждую неделю, каждый месяц. Можно и в приложении: кнопка 🔔
  в шапке, там же список и удаление. В боте: `/reminders` (список с кнопками удаления),
  `/remind <фраза>`.
- **Часовой пояс.** Приложение определяет его по телефону и обновляет при каждом открытии.
  Только с ботом: `/timezone Europe/Moscow` (или `UTC+3`). Пока пояс не задан, Эля попросит
  его указать.
- **Как работает.** Модель превращает фразу в структуру (что, когда, повтор), а дату считает
  код: так не бывает ошибок «через 2 часа» или «в понедельник». Подтверждение («Хорошо, напомню
  завтра в 09:00…») тоже пишет код, поэтому Эля не может пообещать напоминание, которого нет.
  Если время не указано, ставится 09:00. Разбор фразы тратит один запрос из дневного лимита.
- **Доставка.** В боте работает планировщик (проверка каждые 20 секунд). Под напоминанием кнопки
  «+10 мин», «+1 час» и «Готово». Если бот был выключен (например, телефон), напоминание придёт
  после запуска с пометкой «должно было прийти…»; повторяющееся после этого переносится на
  ближайшее будущее время, пропущенные не копятся. Недоставленное (сбой сети) повторяется,
  заблокированный бот — нет.
- До 50 напоминаний на человека, не дальше чем на год вперёд.

## Долговременная память

Эля может запоминать важное о тебе (имя, близких, вкусы, планы) и помнить это между
разговорами. **Память выключена по умолчанию**: включается в настройках приложения («Память»)
или командой `/memory`.

- После ответа модель в фоне выделяет из твоего сообщения долговременные факты и сохраняет
  их; в приложении появляется уведомление «🧠 Запомнила: …». Запрос на выделение делается
  только для сообщений, где ты говоришь о себе, но он входит в дневной лимит запросов.
- Пароли, номера карт и ключи не запоминаются. Фактов не больше 50, каждый до 200 символов.
- Список виден в настройках: факт можно удалить, добавить свой или «Забыть всё».
  В боте: `/memory` — список и переключатель, `/forget` — стереть всё.
- Сохранённые факты добавляются в системный промпт как сведения (а не как указания).
  Пока память выключена, они не используются и не пополняются.

## Mini App

Интерфейс лежит в `webapp/` (HTML, CSS и JavaScript без сборки и сторонних библиотек).
Его раздаёт сам бот: при заданном `WEBAPP_URL` он поднимает веб-сервер на `WEBAPP_PORT`,
ставит кнопку меню рядом с полем ввода и добавляет кнопку «Открыть приложение» в `/start`.

Telegram открывает Mini App только по **публичному HTTPS-адресу**, поэтому серверу нужен
HTTPS-адрес, который ведёт на порт бота:

- **Попробовать на своём компьютере** — туннель, например
  [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/):
  `cloudflared tunnel --url http://localhost:8080` без регистрации выдаст временный адрес вида
  `https://….trycloudflare.com`. Он только для проб: после перезапуска туннеля адрес меняется.
- **Постоянно** — сервер с доменом и обратным прокси с HTTPS (Caddy, nginx), который
  передаёт запросы на `localhost:8080`.

Дальше:

```bash
# .env
WEBAPP_URL=https://твой-адрес
```

Перезапусти бота: в логе появится `Mini App: https://твой-адрес/`. Открой чат с ботом и нажми
кнопку меню «Эля» слева от поля ввода (или `/start` → «Открыть приложение»).

Что умеет приложение:

- лента диалога с общей для бота и приложения историей, разделители по дням;
- оформление ответов: списки, заголовки, цитаты, таблицы, блоки кода с кнопкой копирования;
- быстрые подсказки для старта, индикатор «печатает», повтор отправки при ошибке;
- настройки: тема (как в Telegram, светлая, тёмная — меняется плавно), стиль общения
  (дружелюбный, заботливый, весёлый, деловой), полнота ответа (кратко, обычно, подробно),
  выбор модели, счётчик запросов за сутки, очистка истории. Стиль и полнота хранятся
  на сервере и действуют и в чате с ботом.

**Посмотреть дизайн без Telegram и без ключей** можно в демо-режиме (ответы — заготовки):

```bash
python -m http.server 8000 --directory webapp
# http://localhost:8000/?demo            — приветствие
# http://localhost:8000/?demo=chat       — пример диалога
# добавь &theme=light или &theme=dark, чтобы выбрать тему
```

Как устроена защита: Telegram передаёт приложению строку `initData`, подписанную токеном бота.
Приложение присылает её в каждом запросе, сервер проверяет подпись и срок действия
(`WEBAPP_AUTH_MAX_AGE`), а затем — что Telegram ID есть в `ALLOWED_USER_IDS`. Ключи
ИИ-провайдеров остаются на сервере и в браузер не попадают.

## Настройки (`.env`)

Все параметры с комментариями перечислены в [`.env.example`](.env.example). Основные:

- `AI_PROVIDERS`: порядок провайдеров, например `gemini,openrouter,groq,mistral`.
- `GEMINI_MODELS`, `OPENROUTER_MODELS`, `GROQ_MODELS`, `MISTRAL_MODELS`: модели через запятую
  в порядке приоритета.
- `WEBAPP_URL`: публичный HTTPS-адрес Mini App; пусто — приложение выключено.
  `WEBAPP_HOST` / `WEBAPP_PORT`: где бот слушает запросы приложения.
- `HISTORY_MAX_MESSAGES` / `HISTORY_MAX_CHARS`: сколько истории отправлять модели
  (влияет на расход токенов).
- `RATE_LIMIT_PER_MINUTE`: защита от флуда (общий лимит для бота и приложения).
- `DAILY_REQUEST_LIMIT`: защита квоты; учитывается каждая HTTP-попытка, включая фолбэк.

API приложения (все запросы — с заголовком `Authorization: tma <initData>`):

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/state` | имя ассистента, история, список моделей, счётчик запросов |
| `POST` | `/api/chat` | `{"text": "...", "model": "провайдер:модель"}` → ответ Эли (`model` необязателен) |
| `POST` | `/api/clear` | удалить историю диалога |
| `POST` | `/api/preferences` | `{"style": "...", "verbosity": "..."}` — стиль общения и полнота ответа |
| `POST` | `/api/photo` | multipart: `image` (JPEG/PNG/WebP/GIF, до 5 МБ), `text`, `model` — ответ как у `/api/chat` |
| `POST` | `/api/voice` | тело — запись с микрофона (`audio/webm`, `audio/ogg`, `audio/mp4`…), ответ — `{"text": "..."}` |
| `POST` | `/api/timezone` | `{"tz": "Europe/Moscow"}` — часовой пояс (приложение шлёт его само) |
| `POST` | `/api/reminders/add` | `{"text": "...", "when": "ГГГГ-ММ-ДДTЧЧ:ММ", "repeat": "none\|daily\|weekdays\|weekly\|monthly"}` |
| `POST` | `/api/reminders/delete` | `{"id": N}` — удалить напоминание |
| `POST` | `/api/memory` | `{"enabled": true}` — включить или выключить долговременную память |
| `POST` | `/api/memory/add` | `{"text": "..."}` — добавить факт вручную |
| `POST` | `/api/memory/delete` | `{"id": N}` — забыть один факт, `{"all": true}` — все |

## Бесплатный запуск на Android (Termux)

Бот и приложение работают, пока на телефоне запущен Termux. База хранится в памяти
телефона (`data/assistant.db`) и переживает перезапуски.

```bash
# 1. Один раз: пакеты (сборка pydantic-core может занять 10–20 минут)
pkg update && pkg upgrade
pkg install python git rust binutils build-essential cloudflared termux-api
export ANDROID_API_LEVEL=$(getprop ro.build.version.sdk)

# 2. Один раз: код и зависимости
git clone -b ccr-84f2fee0-3viifm https://github.com/rebirthpython/elya.ai
cd elya.ai
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 3. Один раз: настройки
cp .env.example .env && nano .env   # BOT_TOKEN, ALLOWED_USER_IDS, GEMINI_API_KEY

# 4. Каждый раз: запуск (сам поднимает туннель и подставляет адрес)
./termux/start.sh
```

Адрес туннеля `trycloudflare.com` меняется при каждом запуске, скрипт подставляет его
сам, а бот обновляет кнопку меню.

Скрипт работает как «сторож»: если бот упал, туннель оборвался или адрес перестал отвечать
снаружи (ошибка Cloudflare 1033), он сам поднимает всё заново с новым адресом. При повторяющихся
сбоях (например, нет интернета) пауза между попытками растёт до минуты. Остановить — CTRL+C.
Открывай приложение кнопкой меню «Эля»: старые кнопки в переписке ведут на прежний адрес. Чтобы Android не убивал Termux, в настройках

## Хостинг на Railway

Бот собирается из `Dockerfile`, рабочая папка в контейнере — `/app`, база по умолчанию —
`/app/data/assistant.db`. Диск контейнера временный: без постоянного тома история
и настройки стираются при каждом перезапуске.

Чтобы они сохранялись, подключи к сервису **Volume** с путём монтирования `/app/data`.
Менять `DATABASE_URL` не нужно. После перезапуска в логе должна быть строка
`Database: SQLite /app/data/assistant.db`.

## Безопасность

- Токены и ключи хранятся только в `.env`, который исключён из git.
- Бот отвечает только пользователям из `ALLOWED_USER_IDS` и только в личных чатах.
- Mini App пускает тех же пользователей: каждый запрос подтверждается подписью Telegram
  (`initData`), без неё API отвечает 401, чужому аккаунту — 403.
- Ответы модели в приложении выводятся как текст (без `innerHTML`), страница отдаётся
  со строгой Content-Security-Policy.
- Тексты сообщений не пишутся в логи: в логах только ID, статусы и ошибки провайдеров.
  Параметры SQL в ошибках скрыты.
- Хранится не больше `HISTORY_STORE_LIMIT` сообщений, вся история удаляется командой `/clear`.
- Бот не выполняет код и системные команды из сообщений.
