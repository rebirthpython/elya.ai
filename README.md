# Эля — персональный ИИ-ассистент в Telegram

Ассистент для одного пользователя: естественный диалог на русском от лица Эли с учётом
контекста. Общаться можно двумя способами, память у них общая:

- **Mini App** — HTML5-приложение внутри Telegram с собственным интерфейсом: лента
  сообщений, оформление ответов (списки, код, таблицы), выбор модели, тёмная и светлая темы.
- **Чат с ботом** — обычные сообщения, как раньше.

Отвечают бесплатные языковые модели — до 16 провайдеров и 36 моделей: Gemini, GPT-4.1
из GitHub Models, Mistral, Groq, OpenRouter, NVIDIA, Cloudflare, GLM, GigaChat и другие —
с автоматическим переключением между ними. История сохраняется между перезапусками, доступ только
по Telegram ID.

**Текущий статус: этап 1 (MVP) + Mini App + учебные инструменты + режим кода + монтаж видео.**
Работают: отдельные чаты и проекты («Учёба», «Код», «Личное» — со своими инструкциями и файлами),
Mini App со шторкой (быстрые действия, чаты и проекты, новый чат), `/start`, `/help`,
`/clear`, `/cancel`, диалог с ИИ, история в SQLite, ограничение доступа, лимиты запросов, фолбэк
между моделями и провайдерами, индикатор «печатает…», разбиение длинных ответов, рисование
картинок («нарисуй …», `/draw`), поиск в интернете со ссылками на источники (`/search`),
конспекты и сокращение лекций (`/notes`), презентации с анимациями (`/slides`), режим кода
(`/code`), в котором Эля программирует, монтаж видео (`/video`), работа с документами (PDF, Word,
Excel: поиск ответа со ссылками на страницы и сравнение файлов, `/docs`) и разбор ссылок (статья —
главное и ответы по тексту, видео — по субтитрам) — в чате с ботом и в приложении.

## AI-провайдер

Бот работает с любым **OpenAI-совместимым** API (`POST /chat/completions`) через HTTPX,
без SDK конкретных компаний. Провайдеры перечисляются в `AI_PROVIDERS` в порядке приоритета:
если модель упёрлась в лимит или недоступна, бот пробует следующую модель или провайдера.

Подключить провайдера — значит вписать его бесплатный ключ в `.env`: адрес API и модели
по умолчанию уже настроены (их можно заменить через `<ИМЯ>_MODELS`). Какие модели подключены
сейчас, показывает команда `/models`.

| Провайдер (`AI_PROVIDERS`) | Ключ | Бесплатный доступ (проверь перед запуском) |
|---|---|---|
| **Google Gemini API** (`gemini`) | [AI Studio](https://aistudio.google.com/apikey) | Модели Flash / Flash-Lite без карты; лимиты на проект меняются: [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits). Недоступен с серверов в РФ |
| GitHub Models (`github`) | [токен GitHub](https://github.com/settings/personal-access-tokens) с правом *Models: read* | GPT-4.1, GPT-4.1 mini, GPT-4o mini для любого аккаунта; десятки запросов в день на модель, ответ до 4000 токенов |
| Mistral AI (`mistral`) | [console.mistral.ai](https://console.mistral.ai/api-keys) | План Experiment: Large, Medium, Small; запросы могут использоваться для обучения |
| Groq (`groq`) | [console.groq.com](https://console.groq.com/keys) | GPT-OSS 120B, Qwen и др., лимиты на модель: [rate limits](https://console.groq.com/docs/rate-limits). Ключ же включает голосовые |
| Cerebras (`cerebras`) | [cloud.cerebras.ai](https://cloud.cerebras.ai) | GPT-OSS 120B; условия бесплатного доступа менялись — проверь в кабинете |
| OpenRouter (`openrouter`) | [openrouter.ai/keys](https://openrouter.ai/keys) | Модели `:free` и роутер `openrouter/free`: около 20 запросов в минуту и 50 в сутки, неудачные тоже считаются: [limits](https://openrouter.ai/docs/api-reference/limits) |
| NVIDIA NIM (`nvidia`) | [build.nvidia.com](https://build.nvidia.com) | Бесплатно в программе NVIDIA Developer, для прототипов; запросы логируются |
| Cloudflare Workers AI (`cloudflare`) | [токен](https://dash.cloudflare.com/profile/api-tokens) + `CLOUDFLARE_ACCOUNT_ID` | 10 000 «нейронов» в сутки без карты: Llama 3.3 70B, GLM-4.7 Flash, GPT-OSS |
| Z.ai, GLM (`zai`) | [z.ai](https://z.ai/manage-apikey/apikey-list) | Модели `*-flash` бесплатно, по одному запросу одновременно |
| GigaChat (`gigachat`) | [developers.sber.ru](https://developers.sber.ru/studio) | Freemium для физлиц, **работает с серверов в России**. Нужен сертификат НУЦ Минцифры (см. ниже) |
| Cohere (`cohere`) | [dashboard.cohere.com](https://dashboard.cohere.com/api-keys) | Пробный ключ: около 1000 запросов в месяц, некоммерческое использование |
| Hugging Face (`huggingface`) | [токен](https://huggingface.co/settings/tokens) | Небольшой бесплатный кредит каждый месяц |
| OVHcloud AI Endpoints (`ovh`) | **не нужен** | Анонимно: 2 запроса в минуту на модель с одного IP, серверы в ЕС. С ключом — платно |
| Kilo Gateway (`kilo`) | **не нужен** | Бесплатные модели через роутер, около 200 запросов в час с IP |

| Ollama и другие (`custom`) | — | Любой OpenAI-совместимый сервер: `CUSTOM_*` в `.env` |

Чем больше провайдеров подключено, тем реже Эля упирается в лимиты: провайдеры без ключа
пропускаются, а сервисы, которым ключ не нужен, стоят последними — это запасной вариант на
случай, когда все остальные исчерпали лимиты. Бесплатные каталоги моделей часто меняются:
если модель убрали (ответ 404 или «model not found»), бот откладывает её на 6 часов и сразу
пробует следующую; зависшую модель или недоступный сервер — на минуту и дольше.

**GigaChat и сертификат.** Серверы Сбера подписаны сертификатом НУЦ Минцифры, которому многие
системы не доверяют. Если в логе `TLS certificate is not trusted`, скачай корневой сертификат
на <https://www.gosuslugi.ru/crt> (формат PEM) и укажи путь в `GIGACHAT_CA_BUNDLE` — бот
доверяет ему только для GigaChat.

⚠️ Важно:
- **Регион.** Gemini API доступен не во всех странах, в частности не в РФ. Это касается
  страны, где запущен *сервер бота*, а не страны пользователя. Если сервер в неподдерживаемой
  стране, бот запишет в лог ошибку региона и переключится на резервного провайдера.
- **Приватность.** На бесплатных тарифах провайдеры могут использовать запросы для улучшения
  моделей. Бот предупреждает об этом в `/start` (со списком подключённых сервисов), приложение —
  в настройках. Не хочешь отправлять сообщения какому-то сервису — убери его из `AI_PROVIDERS`.
  Если подключён поиск, поисковые запросы, которые составляет Эля, уходят в поисковый сервис
  (DuckDuckGo или тот, чей ключ указан: Tavily, Brave, Serper.dev, SerpApi).

## Быстрый старт

Нужен Python 3.12+.

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Получи ключ Gemini: <https://aistudio.google.com/apikey>. Для запаса добавь ключи других
   бесплатных провайдеров из таблицы выше — каждый занимает пару минут, и Эля будет реже
   упираться в лимиты. Без единого ключа бот ответит только через сервисы без ключа
   (OVH, Kilo, LLM7, Pollinations) с очень низкими лимитами.
4. Установи и запусти бота:

```bash
cd elya.ai
python3.12 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # заполни BOT_TOKEN, ALLOWED_USER_IDS, GEMINI_API_KEY
python main.py
```

Если всё в порядке, в логе появится строка `Bot @имя_бота started. Providers: gemini[...]`,
а команда `/models` в боте покажет все подключённые модели.
На этом шаге уже работает чат с ботом; приложение включается отдельно — см. следующий раздел.

## Ответы по мере генерации

Эля отвечает «вживую»: текст появляется через секунду-две и дописывается, пока модель его
генерирует, а не после того, как ответ готов целиком.

- **Приложение** читает ответ потоком (`/api/chat/stream`, NDJSON) и плавно показывает текст
  по мере поступления. Если устройство не умеет читать потоки, используется обычный `/api/chat`.
- **Бот** отправляет сообщение примерно через секунду и дописывает его раз в 1,5 секунды
  (чаще Telegram не разрешает), а в конце ставит оформление. Короткие ответы приходят одним
  сообщением.
- Модели переключаются при ошибке, только пока ответ не начался. Если поток оборвался на середине,
  показанная часть остаётся с пометкой об ошибке, а в историю такой обмен не сохраняется.
- Если по пути что-то копит ответ целиком (некоторые прокси), он просто придёт сразу — как раньше.

## Фото

Пришли боту фото (можно с подписью-вопросом: «что это за цветок?», «переведи текст на
скриншоте») — Эля посмотрит и ответит. Картинку, отправленную файлом, тоже понимает (до 5 МБ).
В приложении — скрепка 📎 в поле ввода: выбери фото, добавь подпись и отправь. Телефон сам
уменьшает фото до 1600 px перед отправкой — так быстрее и стираются служебные данные снимка.

- Фото уходит только моделям, которые умеют смотреть картинки (`<ИМЯ>_VISION_MODELS`, см.
  `.env.example`). Модели Gemini умеют по умолчанию. Если таких моделей нет, Эля об этом скажет,
  а скрепки в приложении не будет.
- В истории диалога сохраняется пометка «📷 Фото: подпись» и ответ Эли, сама картинка — нет.

## Картинки

Эля рисует картинки по описанию. Достаточно написать «нарисуй кота-астронавта в стиле
акварели» (или сказать это голосовым) — в чате с ботом или в приложении. Ещё есть команда
`/draw описание`; `/draw` без описания спросит, что нарисовать.

- Просьбу языковая модель превращает в подробный промпт по-английски — так картинки получаются
  заметно лучше — и учитывает недавний диалог, поэтому работают уточнения вроде «а теперь то же
  самое, но зимой». Если модель недоступна, картинка рисуется прямо по словам пользователя.
- Под картинкой кнопка «🔄 Ещё вариант» — новая картинка по тому же описанию.
- В приложении картинка появляется в ленте и одновременно приходит в чат с ботом: приложение
  хранит только текст истории, а из чата картинку удобно сохранить и переслать.
- В истории сохраняется пометка «🎨 Нарисовала картинку: …» с промптом, сама картинка — нет.
  Поэтому Эля помнит, что нарисовала, и может продолжить разговор о картинке.

Рисуют внешние сервисы (`IMAGE_PROVIDERS`, по порядку; без ключа сервис пропускается, если
один упёрся в лимит — пробуется следующий). Без ключей рисование выключено, и Эля честно
говорит, что не умеет. Бесплатные варианты:

1. **Cloudflare Workers AI** (рекомендуется) — модель FLUX.1 [schnell], бесплатно 10 000
   «нейронов» в сутки, это примерно 170 картинок 1024×1024. Зарегистрируйся на
   [dash.cloudflare.com](https://dash.cloudflare.com), скопируй **Account ID** (на главной
   странице аккаунта или в разделе Workers AI) и создай токен: *My Profile → API Tokens →
   Create Token →* шаблон **Workers AI**. В `.env`:
   ```
   CLOUDFLARE_ACCOUNT_ID=…
   CLOUDFLARE_API_TOKEN=…
   ```
2. **Pollinations** — ключ `sk_…` на [enter.pollinations.ai](https://enter.pollinations.ai)
   (вход через GitHub). Сервис начисляет бесплатный баланс («Quest Pollen»), остаток виден
   в личном кабинете. В `.env`: `POLLINATIONS_API_KEY=sk_…`.
3. **Любой OpenAI-совместимый Images API** (OpenAI, Together и т. п., обычно платно):
   `IMAGE_CUSTOM_BASE_URL`, `IMAGE_CUSTOM_API_KEY`, `IMAGE_CUSTOM_MODEL`
   и `custom` в `IMAGE_PROVIDERS`.

У Gemini API бесплатного тарифа для картинок нет, поэтому ключ Gemini для рисования
не используется. `IMAGE_DAILY_LIMIT` (по умолчанию 50) ограничивает число картинок в сутки
отдельно от текстовых запросов; `0` — без ограничения. Описания картинок уходят в выбранный
сервис картинок, а текст просьбы и недавний диалог — в языковую модель, как и обычные сообщения.

### Редактирование картинок

Эля правит картинки по просьбе словами — свои рисунки и присланные фото:

- **Фото с подписью**: «убери людей на заднем плане», «сделай в стиле аниме», «замени фон
  на пляж». Если в подписи вопрос («что на фото?»), Эля отвечает как раньше — решает
  языковая модель.
- **Сразу после картинки** (в течение часа) можно просто написать «сделай её зимней» или
  «а теперь добавь шляпу» — правится последняя картинка: присланная или нарисованная.
- **Ответом на картинку** в чате с ботом — правится именно она.
- `/edit что изменить` — правка картинки, на которую ответили, или последней.
- Под каждой картинкой — кнопки «🔄 Ещё вариант» (для правки — ещё один вариант той же правки)
  и «✏️ Изменить» (дальше правится эта картинка; в приложении — так же, под картинкой в ленте).

Как и для рисования, языковая модель превращает просьбу в инструкцию по-английски
(«Replace the background with a sunny beach. Keep the person unchanged.»), а правит сервис:

1. **Cloudflare Workers AI** — модель FLUX.2 [klein] 4B (`CLOUDFLARE_EDIT_MODEL`, по умолчанию
   `@cf/black-forest-labs/flux-2-klein-4b`), те же ключи и та же бесплатная квота, что для
   рисования. Исходник уменьшается до 511 px (модель принимает картинки меньше 512×512),
   результат — с теми же пропорциями, 1024 px по длинной стороне.
2. **Pollinations** — `POST /v1/images/edits`, модель `POLLINATIONS_EDIT_MODEL` (по умолчанию
   `kontext`; может требовать платный баланс).
3. **Свой OpenAI-совместимый сервис** — `/images/edits` с `IMAGE_CUSTOM_EDIT_MODEL`
   (по умолчанию та же модель, что рисует, например `gpt-image-1`).

`off` в любой из этих переменных выключает правку через этот сервис. Правки считаются в тот же
дневной лимит `IMAGE_DAILY_LIMIT`. В истории сохраняется «✏️ Изменила картинку: …» с инструкцией;
сама картинка хранится только в памяти бота (последняя — час), поэтому после перезапуска
«измени её» без фото не сработает — пришли картинку ещё раз или нажми «✏️ Изменить» под ней.

## Голосовые сообщения

Отправь боту голосовое: Эля покажет, что расслышала («🎤 …»), и ответит как на обычный текст.
В приложении — кнопка микрофона в поле ввода (появляется, когда поле пустое): нажми, говори,
нажми ➤ — распознанный текст уйдёт как обычное сообщение; ✕ отменяет запись. Если Telegram не даёт
приложению доступ к микрофону, кнопка подскажет отправить голосовое прямо в чат с ботом.
Распознаёт Groq Whisper (бесплатный тариф, без карты): достаточно указать `GROQ_API_KEY` в `.env`,
даже если Groq не используется как модель для ответов. Голосовые до 5 минут.
Язык распознавания — русский (`SPEECH_LANGUAGE=ru`); для другого языка укажи его код (`en`, `uk`…)
или `auto`, чтобы Whisper определял язык сам (на коротких записях он при этом может ошибаться).

## Поиск в интернете

Эля умеет искать в интернете и прикладывать ссылки на источники. Когда для ответа нужны свежие
или точные сведения (новости, цены и курсы, погода, расписания, результаты матчей, малоизвестные
факты), она сама решает поискать: в чате появляется «🔎 Ищу в интернете: «запрос»…», а потом
ответ со сносками [1], [2] и списком **«Источники»** со ссылками внизу.

Попросить поиск можно и явно:

- в чате с ботом — `/search курс евро сегодня` или фразой: «погугли …», «найди в интернете …»,
  «дай ссылки на источники»;
- в приложении — кнопка 🌐 в поле ввода: следующее сообщение Эля обязательно проверит
  в интернете.

Как это устроено:

1. Модель получает правило: если нужен поиск, вывести только строку `<search>запрос</search>`.
   Бот перехватывает её по первым символам ответа, пользователь её не видит. Запрос модель
   составляет с учётом диалога, поэтому «а что с ним сейчас?» тоже найдётся.
2. Бот ищет запрос и передаёт модели пронумерованные результаты: заголовок, сайт, дату и фрагмент.
   Модель отвечает по ним и ставит сноски. Результаты помечены как данные со сторонних сайтов:
   команды из них модель выполнять не должна.
3. Список источников добавляет код, а не модель, поэтому ссылки всегда настоящие. В списке только
   результаты, на которые есть сноски, пронумерованные по порядку упоминания (номера в тексте
   меняются так же). Сноски на несуществующие результаты убираются.
4. Если поиск не удался (нет связи, кончилась квота), Эля отвечает по памяти и предупреждает,
   что не смогла проверить сведения.

Ответ с поиском — это два запроса к модели. В историю сохраняется ответ вместе с источниками,
но модели при следующих ответах список ссылок не передаётся, чтобы она не начала дописывать
ссылки сама.

**Подключение.** Поиск работает сразу, без ключей: запасной вариант — DuckDuckGo (HTML-версия
выдачи). У неё нет официального API, поэтому при частых запросах DuckDuckGo может временно
попросить пройти проверку «вы не робот»; тогда Эля ответит по памяти и предупредит. Для надёжности
добавь ключ одного из сервисов, все регистрируются без карты:

| Сервис | Бесплатно (проверь перед запуском) | Переменная |
|---|---|---|
| [Tavily](https://tavily.com) | 1 000 запросов в месяц | `TAVILY_API_KEY` |
| [Brave Search API](https://brave.com/search/api) | бесплатный кредит каждый месяц | `BRAVE_API_KEY` |
| [Serper.dev](https://serper.dev) (выдача Google) | 2 500 запросов один раз при регистрации | `SERPER_API_KEY` |
| [SerpApi](https://serpapi.com) (выдача Google) | 250 запросов в месяц, до 50 в час | `SERPAPI_API_KEY` |
| DuckDuckGo | без ключа и регистрации | `SEARCH_DUCKDUCKGO=true` (по умолчанию) |

Сервисы перебираются по порядку `SEARCH_PROVIDERS` (сервисы без ключа пропускаются): при ошибке
одного бот переключится на следующий. DuckDuckGo всегда добавляется последним, даже если его нет
в списке; `SEARCH_DUCKDUCKGO=false` его отключает (тогда без ключей поиск выключен).

`SEARCH_AUTO=false` оставляет поиск только по явной просьбе. При `SEARCH_AUTO=true` вопросы
о погоде, курсах валют и свежих новостях Эля проверяет в интернете всегда, остальное — по своему
решению. `SEARCH_DAILY_LIMIT` (по умолчанию 100) ограничивает число поисков в сутки: с одним
SerpApi разумно поставить около 8, чтобы месячной квоты хватило на месяц. Счётчик виден в `/help`.

Почему не официальный API Google: Custom Search JSON API закрыт для новых пользователей
и отключается 1 января 2027 года, поэтому выдача Google берётся у Serper.dev и SerpApi.

## Напоминания

Эля присылает напоминание сообщением в Telegram в нужное время.

- **Как поставить.** Напиши обычной фразой: «напомни завтра в 9 позвонить маме», «напомни через
  2 часа проверить пирог», «напоминай каждый день в 8:30 пить воду», «напомни в пятницу…».
  Повторы: каждый день, по будням, каждую неделю, каждый месяц. Можно и в приложении: кнопка 🔔
  в шапке, там же список и удаление. В боте: `/reminders` (список с кнопками удаления),
  `/remind <фраза>`.
- **Часовой пояс.** Приложение определяет его по телефону и обновляет при каждом открытии.
  Только с ботом: `/timezone Europe/Moscow` (или `UTC+3`). Пока пояс не задан, Эля попросит
  его указать.
- **Как работает.** Модель превращает фразу в структуру (что, когда, повтор), а дату считает
  код: так не бывает ошибок «через 2 часа» или «в понедельник». Подтверждение («Хорошо, напомню
  завтра в 09:00…») тоже пишет код, поэтому Эля не может пообещать напоминание, которого нет.
  Если время не указано, ставится 09:00. Разбор фразы тратит один запрос из дневного лимита.
- **Доставка.** В боте работает планировщик (проверка каждые 20 секунд). Под напоминанием кнопки
  «+10 мин», «+1 час» и «Готово». Если бот был выключен (например, телефон), напоминание придёт
  после запуска с пометкой «должно было прийти…»; повторяющееся после этого переносится на
  ближайшее будущее время, пропущенные не копятся. Недоставленное (сбой сети) повторяется,
  заблокированный бот — нет.
- До 50 напоминаний на человека, не дальше чем на год вперёд.

## Инструкции (как в ChatGPT)

В настройках есть страница **«Инструкции»** с двумя полями: «Что Эле знать о тебе?» и «Как Эле
отвечать?» (до 1500 символов каждое). Пишешь один раз — и Эля учитывает это в каждом разговоре,
в приложении и в чате с ботом, без повторов для каждой задачи. Под полями есть подсказки-заготовки
(«Без воды», «С примерами», «Кто я» и др.), а переключатель позволяет временно выключить инструкции.

- Изменения сохраняются кнопкой «Сохранить» или автоматически при возврате назад.
- В боте: `/instructions` — посмотреть, включить/выключить и открыть редактор в приложении.
- Инструкции важнее выбранного стиля и полноты ответа, но не правил безопасности.
- Хранятся на сервере отдельно для каждого пользователя.

## Долговременная память

Эля может запоминать важное о тебе (имя, близких, вкусы, планы) и помнить это между
разговорами. **Память выключена по умолчанию**: включается в настройках приложения («Память»)
или командой `/memory`.

- После ответа модель в фоне выделяет из твоего сообщения долговременные факты и сохраняет
  их; в приложении появляется уведомление «🧠 Запомнила: …». Запрос на выделение делается
  только для сообщений, где ты говоришь о себе, но он входит в дневной лимит запросов.
- Пароли, номера карт и ключи не запоминаются. Фактов не больше 50, каждый до 200 символов.
- Список виден в настройках: факт можно удалить, добавить свой или «Забыть всё».
  В боте: `/memory` — список и переключатель, `/forget` — стереть всё.
- Сохранённые факты добавляются в системный промпт как сведения (а не как указания).
  Пока память выключена, они не используются и не пополняются.

## Mini App

Интерфейс лежит в `webapp/` (HTML, CSS и JavaScript без сборки и сторонних библиотек).
Его раздаёт сам бот: при заданном `WEBAPP_URL` он поднимает веб-сервер на `WEBAPP_PORT`,
ставит кнопку меню рядом с полем ввода и добавляет кнопку «Открыть приложение» в `/start`.

Telegram открывает Mini App только по **публичному HTTPS-адресу**, поэтому серверу нужен
HTTPS-адрес, который ведёт на порт бота:

- **Попробовать на своём компьютере** — туннель, например
  [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/):
  `cloudflared tunnel --url http://localhost:8080` без регистрации выдаст временный адрес вида
  `https://….trycloudflare.com`. Он только для проб: после перезапуска туннеля адрес меняется.
- **Постоянно** — сервер с доменом и обратным прокси с HTTPS (Caddy, nginx), который
  передаёт запросы на `localhost:8080`.

Дальше:

```bash
# .env
WEBAPP_URL=https://твой-адрес
```

Перезапусти бота: в логе появится `Mini App: https://твой-адрес/`. Открой чат с ботом и нажми
кнопку меню «Эля» слева от поля ввода (или `/start` → «Открыть приложение»).

Что умеет приложение:

- лента диалога с общей для бота и приложения историей, разделители по дням;
- оформление ответов: списки, заголовки, цитаты, таблицы, блоки кода с кнопкой копирования;
- быстрые подсказки для старта, индикатор «печатает», повтор отправки при ошибке;
- боковая шторка (кнопка ≡ слева вверху): нарисовать картинку, напоминания, память,
  инструкции, настройки, проекты и список чатов (подробнее — в разделе «Чаты и проекты»).
  Кнопка «Новый чат» (внизу шторки и ✎ в шапке) открывает пустой чат, а прошлый остаётся
  в списке. Очистить открытый чат — в настройках или `/clear` в боте;
- настройки: тема (как в Telegram, светлая, тёмная — меняется плавно), стиль общения
  (дружелюбный, заботливый, весёлый, деловой), полнота ответа (кратко, обычно, подробно),
  выбор модели, счётчик запросов за сутки, очистка истории. Стиль и полнота хранятся
  на сервере и действуют и в чате с ботом.

**Посмотреть дизайн без Telegram и без ключей** можно в демо-режиме (ответы — заготовки):

```bash
python -m http.server 8000 --directory webapp
# http://localhost:8000/?demo            — приветствие
# http://localhost:8000/?demo=chat       — пример диалога
# добавь &theme=light или &theme=dark, чтобы выбрать тему
```

Как устроена защита: Telegram передаёт приложению строку `initData`, подписанную токеном бота.
Приложение присылает её в каждом запросе, сервер проверяет подпись и срок действия
(`WEBAPP_AUTH_MAX_AGE`), а затем — что Telegram ID есть в `ALLOWED_USER_IDS`. Ключи
ИИ-провайдеров остаются на сервере и в браузер не попадают.

## Режим кода

Команда **`/code`** переводит Элю в режим кода: она отвечает как программист — пишет
и объясняет код, ищет ошибки, делает ревью. В обычном режиме Эля тоже может показать пример
кода, но режим кода настроен именно под эту работу.

| Команда | Что делает |
|---|---|
| `/code` | включает режим кода и рассказывает, что в нём можно делать |
| `/code напиши парсер CSV на Python` | включает режим и сразу отвечает на задачу |
| `/code off` | возвращает обычное общение (или кнопка «💬 Обычный режим» под сообщением) |

Что меняется в режиме кода:

- **Отдельный системный промпт** (`ai/prompts.py`): рабочий код целиком и без заглушек,
  минимальные правки чужого кода, поиск причины ошибки, а не симптома, язык и стек — из
  сообщений собеседника (по умолчанию Python). Эля не запускает код и честно об этом говорит:
  не пишет «проверено» и не выдумывает вывод программы, функции и версии библиотек.
- **Параметры генерации**: ниже температура (`CODE_TEMPERATURE`, 0.2) и длиннее ответ
  (`CODE_MAX_OUTPUT_TOKENS`, 4096), в контекст помещается больше истории
  (`CODE_HISTORY_MAX_CHARS`, 40 000 символов) — код длиннее обычных реплик.
- **Файлы с кодом**: пришли боту файл (`.py`, `.js`, `.json`, `.txt` и любой другой текстовый,
  до 1 МБ) с вопросом в подписи — Эля прочитает его и ответит. Файл остаётся в истории,
  так что о нём можно спрашивать дальше. Из длинного файла читаются первые
  `CODE_MAX_FILE_CHARS` символов (30 000), и Эля об этом предупреждает. Скриншот ошибки
  тоже подойдёт, если подключена модель, понимающая фото.
- **Длинный код — ещё и файлом**: блок кода от 50 строк Эля присылает и сообщением,
  и документом (`main.py`, `code.js`…), чтобы его было удобно сохранить.
- **Подсветка синтаксиса**: блоки кода уходят в Telegram с указанием языка; если ответ
  не помещается в одно сообщение, блок корректно закрывается и открывается в следующем.
- **Mini App**: тот же режим включается переключателем «Режим кода» в настройках (⋯).
  В нём можно вставить в сообщение до 16 000 символов кода вместо обычных 4000. Режим общий:
  включённый в чате действует в приложении, и наоборот.

Режим хранится в базе на пользователя и переживает перезапуск бота. Напоминания в режиме
кода работают как обычно, но фраза «напомни» внутри вставленного кода или файла
за просьбу о напоминании не принимается.

## GitHub: код прямо в репозиторий

Эля пишет код и отправляет его в твой репозиторий одним коммитом — так удобно делать,
например, своего Telegram-бота вместе с ней.

**Подключить** (один раз):

1. Создай токен: [classic со scope `repo`](https://github.com/settings/tokens/new?scopes=repo&description=Elya)
   (проще) или [fine-grained](https://github.com/settings/personal-access-tokens/new) с правами
   *Contents: Read and write* (и *Administration: Read and write*, чтобы Эля могла создавать репозитории).
2. Пришли его боту: `/github ghp_…` (или в приложении: настройки → GitHub). Бот проверит токен,
   сохранит его в базе зашифрованным (ключ выводится из `BOT_TOKEN`) и сразу удалит сообщение
   с токеном. Токен, присланный без команды, тоже не уходит модели — бот его подключает.
   Вместо этого токен можно задать на сервере: `GITHUB_REPO_TOKEN` в `.env`.
3. Выбери репозиторий: `/repo` (кнопки с недавними), `/repo владелец/имя` или создай новый
   приватный: `/repo new my-telegram-bot`.

**Работать:**

- Попроси написать код (удобнее в проекте «Код»): «напиши телеграм-бота на aiogram, который
  отвечает на /start и пересылает сообщения». Эля знает список файлов репозитория и пишет
  файлы целиком, с путями — «Файл `bot.py`:» перед каждым блоком.
- Под ответом появляется кнопка «🐙 Отправить в GitHub» (в боте и в приложении) — все файлы
  уходят одним коммитом в выбранную ветку, в ответ — ссылка на коммит. `/push [сообщение]` —
  отправить файлы из последнего такого ответа. Пустой репозиторий тоже подходит.
- `/pull bot.py [задача]` — показать Эле файл из репозитория: он попадает в разговор как
  присланный файл, например `/pull bot.py добавь команду /help`.
- `/github` — что подключено и какие файлы в репозитории; `/github off` — отключить и удалить токен.

Файлы для кнопки хранятся в памяти бота (последние 50 ответов); после перезапуска попроси
прислать файлы ещё раз. Сам код Эля не запускает — запусти бота у себя: `pip install -r
requirements.txt`, затем `BOT_TOKEN=… python bot.py`.

**Код файлами.** Блок кода, подписанный именем файла («Файл `bot.py`:», `requirements.txt`),
приходит ещё и файлом — любой длины; длинный код — тоже; а если попросить «пришли файлом» —
файлами приходят все блоки. Небольшой проект (до 5 файлов) приходит и файлами, и ZIP-архивом.

## Готовые файлы на выходе

Эля не только отвечает текстом, но и сразу отдаёт файлы:

| Просьба | Что приходит |
|---|---|
| «Напиши реферат про Петра I», «доклад о фотосинтезе», «эссе», «… в ворде» | ответ в чате и **DOCX** с оформлением учебной работы: Times New Roman 14, полуторный интервал, поля 3/1,5/2 см, абзацный отступ, номера страниц, заголовки разделов, списки и таблицы |
| «Сделай презентацию про космос на 8 слайдов» | **PPTX** — тот же конвейер, что `/slides`: в боте план, правки и выбор оформления; в приложении — сразу файл в оформлении по умолчанию, ход работы виден в ленте |
| «Сделай проект бота на aiogram», «сайт-визитку», «скинь zip» | **ZIP** со всеми файлами по папкам (пути — из строк «Файл `src/main.py`:» перед блоками кода) |
| Любой ответ с веб-страницей (`index.html` целиком) | **HTML**: в боте — файл и кнопка «👁 Посмотреть в приложении», в приложении — кнопка «Открыть» с предпросмотром прямо в Mini App |

- Как это решается: просьбы распознаются по словам («реферат», «в ворде», «презентацию»,
  «проект», «zip»), и для документа и проекта в промпт добавляется правило — писать документ
  целиком, с заголовком и разделами, а файлы проекта — с путями; длина ответа увеличивается до
  `STUDY_MAX_OUTPUT_TOKENS`. Файлы собирает `services/artifacts.py` уже из готового ответа.
  Архив собирается, если в ответе два файла и больше; один файл кода в режиме кода, как и
  раньше, приходит отдельным файлом.
- **В приложении** под ответом — карточки файлов с кнопкой «Скачать» (Telegram скачивает файл
  сам, в старых клиентах ссылка открывается в браузере). Файлы хранятся в базе (`user_files`)
  30 дней, не больше 50 последних; ссылка содержит случайный ключ, без него файл не найти.
  Презентация из приложения приходит ещё и в чат с ботом.
- **Предпросмотр HTML** открывается поверх чата в изолированной «песочнице» (`sandbox` без
  доступа к приложению, его данным и cookie): скрипты и стили страницы работают, но прочитать
  что-то из Mini App она не может. Скачанный HTML тоже не выполняется в адресе приложения.

## Чаты и проекты

**Чаты.** У каждого чата своя переписка: в новом чате Эля не видит старых сообщений.
Прошлые чаты не пропадают — к ним можно вернуться и продолжить.

- **В приложении**: «Новый чат» внизу шторки или кнопка ✎ в шапке. В шторке — список чатов
  (новые сверху, открытый подсвечен); «⋯» у чата — переименовать или удалить. Название чат
  получает сам — по первому сообщению.
- **В боте**: `/new` — новый чат, `/chats` — последние чаты кнопками, нажатие открывает чат
  и показывает последний ответ. Открытый чат общий: что написано в боте, видно в том же
  чате в приложении, и наоборот.
- `/clear` и «Очистить этот чат» в настройках очищают только открытый чат.

**Проекты** — папки для чатов. Сразу есть «📚 Учёба», «💻 Код» и «🌿 Личное»; их можно
переименовать, удалить и добавить свои (до 20). У проекта свои:

- **инструкции** — добавляются ко всем его чатам (вдобавок к общим инструкциям);
- **файлы** — PDF, Word, таблицы, которые видны во всех его чатах (до 20). Файл, присланный
  в сам чат, виден только в этом чате;
- **режим кода** — в проекте «Код» он включён для всех чатов, даже если общий режим выключен.

В приложении проекты — «таблетки» над списком чатов: нажатие показывает чаты проекта, и
«Новый чат» создаёт чат в нём; «⚙️ Настроить» — значок, название, инструкции, режим кода,
файлы и удаление (чаты удалённого проекта переходят в «Без проекта»). Проект открытого чата
виден в шапке. В боте: `/projects` — список проектов кнопками (нажатие продолжает последний
чат проекта), `/project Название` — перейти в проект или создать новый.

При обновлении старая история сама делится на чаты по отметкам «Новый чат», а присланные
раньше документы попадают в последний из них. Устроено это в `memory/chats.py`: таблицы
`chats`, `projects` и `chat_state` (открытый чат), у сообщений и документов — столбец
`chat_id` (новые столбцы добавляются в старую базу при запуске).

## Документы: PDF, Word и таблицы

Пришли учебник, договор или таблицу — Эля найдёт ответ в тексте и укажет, откуда он:
«Митохондрии вырабатывают энергию (стр. 42)». Два файла можно сравнить.

- **Форматы**: PDF, Word (.docx), Excel (.xlsx), CSV, .txt и .md — до 20 МБ (больше Telegram
  не даёт ботам скачивать). Старые .doc и .xls нужно пересохранить в .docx и .xlsx. Сканы
  (PDF из картинок) не читаются: такую страницу лучше прислать фото.
- **Как спросить.** Пришли файл с вопросом в подписи или сначала файл, а потом вопросы
  обычными сообщениями: «найди, что сказано про фотосинтез», «что на стр. 40?». Файл без
  подписи бот просто подтверждает, не тратя запрос к модели. В приложении файл прикрепляется
  скрепкой 📎; без вопроса Эля коротко расскажет, о чём документ.
- **Сравнение.** Пришли два файла (можно одним сообщением) и напиши «сравни эти два файла»:
  Эля перечислит различия со ссылками на места в обоих.
- **Ссылки на места**: в PDF — номер страницы файла; в Word — страница, если файл сохранён
  в Word (он отмечает, где начинаются страницы), иначе раздел и номера абзацев; в таблицах —
  лист и номера строк.
- **Документы принадлежат чату** (или проекту — тогда видны во всех его чатах): Эля
  учитывает их в каждом следующем сообщении этого чата. Их список — `/docs` в боте или плашка над
  полем ввода в приложении; лишний можно убрать. В чате держится до 5 документов.

### Как это устроено

Документ целиком в бесплатную модель не помещается, поэтому `services/documents.py`:

1. Разбирает файл на фрагменты по ~1500 символов с пометкой места («стр. 12», «лист «Итоги»,
   строки 2–40»). PDF — `pypdf`, Word — `python-docx`, Excel — `openpyxl`. Фрагменты хранятся
   в базе (таблица `user_documents`), поэтому переживают перезапуск бота.
2. На каждое сообщение подбирает подходящие фрагменты простым поиском по словам (BM25 с
   отсечением окончаний) — без внешних сервисов и платных эмбеддингов. Названная страница
   («стр. 40») попадает в выборку всегда.
3. Добавляет фрагменты в системный промпт вместе с правилом: отвечать по ним, ставить ссылку
   на место после каждого утверждения и честно говорить, если ответа в них нет.
4. Для сравнения сопоставляет строки двух файлов (`difflib`): модель получает долю совпадающего
   текста и в первую очередь фрагменты, где файлы расходятся.

Если сообщение не о документах, фрагменты не добавляются — только короткая пометка, что
документы есть. Поиск в интернете на вопросы по документу не запускается (если его не
попросили явно). Сколько символов фрагментов добавлять — `DOCUMENTS_CONTEXT_CHARS`
(по умолчанию 10000; больше — точнее, но дольше и дороже для квоты).

## Разбор ссылок: статьи и видео

Скинь ссылку на статью — Эля откроет её сама, прочитает доступный текст, выделит главное
и будет отвечать по содержанию. Для видео она работает с доступными субтитрами.

- **Просто ссылка** — суть статьи, ключевые мысли по пунктам и вывод автора, а в конце пара
  вопросов, которые можно задать. **Ссылка с вопросом** («из чего катализатор? https://…») —
  ответ на вопрос по тексту статьи. Дальше по статье можно спрашивать обычными сообщениями:
  она остаётся в чате как документ (видна в `/docs` и на плашке в приложении).
- **Что читается**: обычные веб-страницы (основной текст без меню, рекламы, кнопок «поделиться»
  и комментариев; заголовок, автор, дата), PDF и текстовые файлы по прямой ссылке.
- **Видео**: YouTube (`youtube.com/watch`, `youtu.be`, Shorts, трансляции) — по субтитрам:
  сначала авторским, потом автоматическим; русским, потом английским, потом любым. В ответе —
  таймкоды. Ещё — страницы с плеером, у которого есть дорожка субтитров (`<track>`), и прямые
  ссылки на `.vtt`/`.srt`. Само видео и звук Эля не смотрит: нет субтитров — она честно
  скажет об этом и опирается только на название и описание.
- **Только доступное**: платный доступ, страницы за входом, капча и закрытые видео не
  обходятся. Если открылась лишь часть текста (анонс платной статьи, сайт на скриптах), Эля
  предупредит; не открылась совсем — объяснит почему и предложит вставить текст в чат.
- В одном сообщении читаются до 3 ссылок; пока Эля читает, в чате видно «🔗 Читаю ссылку…».

Устроено в `services/links.py`: страница скачивается (до 5 МБ, PDF — до 20 МБ), текст
вынимается встроенным `html.parser` (плюс `articleBody` из JSON-LD), субтитры YouTube берутся
из данных плеера. Дальше текст режется на фрагменты и работает как документ (см. выше): к
каждому сообщению подбираются нужные куски. Ссылки на адреса внутренней сети (`localhost`,
`10.*`, `192.168.*`, метаданные облака) не открываются — в том числе после перенаправлений.
Выключить разбор ссылок — `LINKS_ENABLED=false`.

## Конспекты и презентации

**`/notes`** — конспект в Word. Пришли текст лекции или расшифровку (можно несколькими
сообщениями — бот склеит), файл `.txt`, `.md`, `.docx`, `.pdf` или просто тему, затем выбери режим:

| Режим | Что получится |
|---|---|
| 📝 Подробный конспект | 25–40% объёма лекции: разделы, определения, таблицы терминов и фактов, вопросы для самопроверки |
| ✂️ Кратко | Выжимка на 8–15% объёма: перечитать за 2–3 минуты перед занятием |
| 🔍 Главные детали | Шпаргалка: термины, даты, числа, имена, что будет на экзамене |

**`/slides`** — презентация PowerPoint. Пришли тему (`Фотосинтез, 8 слайдов`) или материал,
бот покажет план — его можно поправить обычным сообщением («убери 3-й слайд, добавь про
последствия») или попросить другой. Потом выбираешь оформление: строгое, яркое, минимализм или
тёмное. В файле: титульный слайд, слайды семи типов (тезисы, сравнение, хронология, цифры,
цитата, раздел, выводы), появление пунктов по щелчку, переходы между слайдами и заметки
докладчика — что говорить на каждом слайде.

### Как бот добивается качества

Модель пишет только содержание в строгом JSON, а код проверяет его по правилам и при нарушениях
отправляет ей конкретный список замечаний на исправление. Оформление целиком делает код по
шаблонам, поэтому оно не зависит от модели.

- **Сначала выписка, потом конспект.** Первым запросом модель выписывает из материала все
  термины, даты, числа, имена, формулы, акценты лектора («это будет на экзамене»),
  организационное (ДЗ, сроки) и непонятные места. Затем пишет конспект, а код проверяет, что
  каждый термин и факт из выписки в него попал — с учётом склонений («мембрана» найдётся
  в «мембраны») и разных записей чисел.
- **Правила сокращения** (`study/prompts.py`): убирать слова-паразиты, повторы, отступления
  и «откройте тетради», сохранять определения, конкретику и причинно-следственные связи;
  сокращать слова, а не смысл; ничего не выдумывать.
- **Объём по режиму** проверяется кодом: слишком длинную «выжимку» и слишком короткий
  «подробный конспект» модель переделывает.
- **Правила слайдов** (`study/slides.py`): одна мысль на слайд, 2–5 тезисов до 90 символов,
  заголовок до 60, заметки докладчика на каждом слайде, разнообразие типов, выводы последним
  слайдом, цифры и цитаты только реальные. Если модель не уложилась даже после замечаний, код
  сам доводит слайды до лимитов, а не поместившиеся пункты переносит в заметки докладчика.
- **Кегль подбирается под текст**, чтобы ничего не вылезало за слайд.
- **Бережный расход квоты**: на конспект и на презентацию уходит 2–4 запроса к модели
  (не больше одного исправления на шаг).

Без исходного материала (только тема) конспект помечается как составленный по общим знаниям —
факты стоит сверить с учебником.

## Монтаж видео

Пришли боту видео (или несколько — можно альбомом) и скажи словами, что сделать. Или начни
с `/video`. Эля смонтирует и пришлёт результат, а дальше его можно править следующими
сообщениями: «а теперь ускорь», «убери надпись», «верни как было».

**В приложении** — то же самое: прикрепи видео скрепкой 📎 (или напиши `/video`, или открой
шторку слева → «Монтаж видео») и добавь просьбу. Над полем ввода появится плашка «🎬 Монтаж · N клипов» с кнопкой «Готово»; пока она
видна, всё, что пишешь, идёт монтажёру. Ход работы виден в ленте («Готовлю фрагменты 3 из 12»),
результат можно посмотреть прямо в приложении, а файл бот присылает в чат — там он сохраняется.
Из приложения можно загрузить видео до `VIDEO_UPLOAD_MAX_MB` (100 МБ): ограничение Telegram
в 20 МБ касается только файлов, присланных в чат. Монтаж общий: клип можно прислать в чат,
а просьбу написать в приложении, и наоборот.

| Что умеет | Как попросить |
|---|---|
| Обрезать, вырезать кусок, переставить и повторить фрагменты | «обрежь первые 5 секунд», «вырежи с 0:10 до 0:15», «сначала второй клип» |
| Склеить несколько клипов | «склей» или кнопка «🔗 Просто склеить» |
| Ускорить и замедлить (×0,25…×4) | «ускорь в 1,5 раза», «конец замедли вдвое» |
| Вырезать паузы и тишину | кнопка «🤐 Убрать паузы» или «убери паузы» |
| Субтитры из речи | кнопка «💬 Субтитры» (нужен `GROQ_API_KEY`) |
| Надписи поверх видео | «подпиши в начале „Лето 2026“», «внизу до конца — мой ник» |
| Формат 9:16 (Reels, TikTok, Shorts), 16:9, 1:1, 4:5 | кнопка «📱 Вертикально 9:16» или «сделай квадрат с чёрными полосами» |
| Поворот, отражение, стабилизация | «поверни на 90°», «отзеркаль», «убери тряску» |
| Цвет: ч/б, тёплый, холодный, сочный, винтаж, светлее | «сделай чёрно-белым» |
| Переходы между фрагментами, затемнение в начале и конце | «плавные переходы», «затемнение в конце» |
| Громкость, без звука, шумоподавление | «сделай тише», «убери звук», «убери шум» |
| Музыка из присланного аудиофайла | пришли mp3/m4a и напиши «наложи музыку потише» |
| Гифка, кружок Telegram, только звук | «сделай гифку», кнопка «⭕ Кружочек», «вытащи звук» |
| Монтаж по смыслу | «оставь только где я говорю про цены» — Эля сначала послушает видео (нужен `GROQ_API_KEY`) |

Под результатом кнопки: частые действия (каждое — без запроса к модели), «↩️ Отменить» —
вернуть прошлый вариант (мгновенно, без повторного монтажа) и «✅ Готово» — закончить и стереть
файлы. Просьбу можно сказать голосовым или написать в подписи к видео.

### Как это устроено

- **Модель только планирует.** Она превращает просьбу в план монтажа (JSON): какие фрагменты
  каких клипов, скорость, формат, надписи. Код проверяет план по длительности клипов: время
  за пределами клипа, неизвестный формат и т. п. модель исправляет по списку замечаний.
  На одну просьбу — 1–2 запроса к модели; кнопки модель не тратят.
- **Монтирует ffmpeg**, а описание под видео («✂️ Фрагмент 0:05–0:30, 🤐 Паузы вырезаны −0:12»)
  пишет код — поэтому оно всегда совпадает с тем, что в видео на самом деле.
- **Паузы** ищет ffmpeg по тишине в звуке; края фраз остаются с небольшим запасом.
- **Субтитры** распознаются по уже смонтированному звуку, поэтому совпадают с видео по времени
  и после вырезания пауз и ускорения. Расшифровка запоминается: повторный монтаж тех же
  фрагментов не тратит лимит Whisper.
- Видео собирается в два шага: каждый фрагмент кодируется отдельно в одинаковый формат,
  затем всё склеивается и накладываются надписи, затемнения и музыка. Так длинное видео
  с десятками вырезанных пауз не съедает память.
- Битрейт подбирается так, чтобы результат поместился в 50 МБ — лимит Telegram на отправку.

### Ограничения

- **В чате с ботом — видео до 20 МБ.** Больше Telegram не даёт ботам скачивать файлы. Присылай
  видео как обычное видео, а не файлом: Telegram сам его сожмёт. Или загрузи его через
  приложение — там до `VIDEO_UPLOAD_MAX_MB` (100 МБ).
- До `VIDEO_MAX_CLIPS` клипов за раз (10), результат — до `VIDEO_MAX_SECONDS` (10 минут),
  кружок — до минуты.
- Эля не видит картинку в видео: монтирует по времени, звуку и расшифровке речи. Спецэффекты,
  удаление предметов из кадра и монтаж «где собака» она не делает и честно об этом говорит.
- Монтаж идёт по одному видео за раз, ffmpeg работает с пониженным приоритетом, чтобы бот
  продолжал отвечать. На телефоне Full HD монтируется заметно медленнее, чем на сервере; если
  долго, уменьши `VIDEO_MAX_SIDE` до 1280.
- Файлы лежат во временной папке, пока идёт монтаж, и удаляются по «Готово», `/cancel`
  и при перезапуске бота.

**Нужен ffmpeg** (без него бот работает, но монтаж выключен — `/video` об этом скажет):

| Где | Как установить |
|---|---|
| Termux | `pkg install ffmpeg` |
| Ubuntu, Debian | `sudo apt install ffmpeg fonts-dejavu-core` |
| Docker / Railway | уже в `Dockerfile` |
| macOS | `brew install ffmpeg` |

После запуска в логе видно, включён ли монтаж: `Video editing: on (ffmpeg 6.1.1; text, subtitles)`.
Надписям и субтитрам нужен ffmpeg с libass и шрифт с кириллицей. Если ffmpeg собран без libass,
монтаж работает, а на просьбу о надписях Эля объяснит, почему их не будет.

## Настройки (`.env`)

Все параметры с комментариями перечислены в [`.env.example`](.env.example). Основные:

- `AI_PROVIDERS`: порядок провайдеров (по умолчанию — все 16, см. таблицу выше).
- `<ИМЯ>_API_KEY`: ключ провайдера, например `GEMINI_API_KEY`, `GITHUB_API_KEY`.
- `<ИМЯ>_MODELS` / `<ИМЯ>_VISION_MODELS`: модели для текста и для фото через запятую
  в порядке приоритета; по умолчанию — подобранные бесплатные.
- `<ИМЯ>_BASE_URL`, `<ИМЯ>_MAX_TOKENS`, `<ИМЯ>_CA_BUNDLE`: другой адрес API, потолок длины
  ответа и свой корневой сертификат. `CLOUDFLARE_ACCOUNT_ID` — ID аккаунта Cloudflare.
- `WEBAPP_URL`: публичный HTTPS-адрес Mini App; пусто — приложение выключено.
  `WEBAPP_HOST` / `WEBAPP_PORT`: где бот слушает запросы приложения.
- `HISTORY_MAX_MESSAGES` / `HISTORY_MAX_CHARS`: сколько истории отправлять модели
  (влияет на расход токенов).
- `RATE_LIMIT_PER_MINUTE`: защита от флуда (общий лимит для бота и приложения).
- `DAILY_REQUEST_LIMIT`: защита квоты; учитывается каждая HTTP-попытка, включая фолбэк.
- `IMAGE_PROVIDERS`, `CLOUDFLARE_ACCOUNT_ID` / `CLOUDFLARE_API_TOKEN`, `POLLINATIONS_API_KEY`,
  `IMAGE_DAILY_LIMIT`: рисование картинок (см. раздел «Картинки»).
- `STUDY_MAX_OUTPUT_TOKENS` / `STUDY_MAX_INPUT_CHARS`: длина ответа модели для конспектов
  и презентаций и максимальный размер материала.
- `VIDEO_MAX_CLIPS`, `VIDEO_MAX_SECONDS`, `VIDEO_MAX_SIDE`, `VIDEO_TIMEOUT`, `VIDEO_UPLOAD_MAX_MB`:
  лимиты монтажа видео; `FFMPEG_PATH` / `FFPROBE_PATH` — если ffmpeg не в `PATH`.
- `CODE_MAX_OUTPUT_TOKENS` / `CODE_TEMPERATURE` / `CODE_HISTORY_MAX_CHARS` /
  `CODE_MAX_FILE_CHARS`: режим кода — длина ответа, температура, размер истории
  и сколько символов читать из присланного файла.
- `LINKS_ENABLED`: разбор ссылок на статьи и видео (по умолчанию включён).
- `TAVILY_API_KEY` / `BRAVE_API_KEY` / `SERPER_API_KEY` / `SERPAPI_API_KEY`: поиск в интернете;
  без ключей работает DuckDuckGo (`SEARCH_DUCKDUCKGO=false` — выключить).
  `SEARCH_AUTO`, `SEARCH_LANGUAGE`, `SEARCH_REGION`, `SEARCH_MAX_RESULTS`, `SEARCH_DAILY_LIMIT` —
  см. раздел «Поиск в интернете».

## Сервер и автообновление

Чтобы бот работал круглосуточно и сам обновлялся после каждого `git push`, разверни его на
Linux-сервере с systemd (Ubuntu, Debian и т. п.). Лучше завести для бота отдельного
пользователя и выполнять команды под ним:

```bash
git clone https://github.com/rebirthpython/elya.ai.git
cd elya.ai
cp .env.example .env && nano .env   # заполни BOT_TOKEN, ALLOWED_USER_IDS, GEMINI_API_KEY
deploy/install.sh
```

Для монтажа видео заранее поставь ffmpeg: `sudo apt install ffmpeg fonts-dejavu-core`.

`install.sh` создаёт `.venv`, проверяет `.env` и регистрирует user-сервисы systemd:

- `elya-bot` — сам бот: стартует вместе с сервером и перезапускается при падении;
- `elya-update.timer` — раз в минуту запускает `deploy/update.sh`.

`update.sh` проверяет, появились ли новые коммиты в ветке, на которой стоит клон
(другую можно задать через `DEPLOY_BRANCH`). Если появились, скрипт:

1. подтягивает их (`git merge --ff-only`; `.env` и история в `data/` не затрагиваются);
2. обновляет зависимости, если изменился `requirements*.txt`;
3. прогоняет тесты;
4. перезапускает бота и 20 секунд следит, что он не упал;
5. если любой шаг не удался, возвращает предыдущую версию и больше не пытается ставить
   этот коммит. Следующий пуш с исправлением поставится как обычно.

| Команда | Что делает |
|---|---|
| `journalctl --user -u elya-update -f` | лог обновлений: что поставилось и почему откатилось |
| `journalctl --user -u elya-bot -f` | лог бота |
| `systemctl --user restart elya-bot` | перезапуск, например после правки `.env` |
| `deploy/update.sh --force` | переустановить последнюю версию, даже отклонённую ранее |
| `systemctl --user disable --now elya-update.timer` | отключить автообновление |

Важно:

- С одним токеном бот может работать только в одном экземпляре. Если запустить его ещё
  и у себя (`python main.py`), Telegram вернёт ошибку `Conflict`.
- Не правь файлы репозитория прямо на сервере: пока такие изменения не закоммичены или не
  убраны (`git stash`), обновление останавливается с ошибкой в логе.
- Если репозиторий станет приватным, серверу понадобится доступ на чтение, например
  [deploy key](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/managing-deploy-keys).
- Правки `update.sh` применяются сами со следующего запуска. Правки `install.sh` (unit-файлы,
  частота проверки `UPDATE_SCHEDULE`, `RUN_TESTS`) вступают в силу после его повторного запуска.

## Бесплатный запуск на Android (Termux)

Бот и приложение работают, пока на телефоне запущен Termux. База хранится в памяти
телефона (`data/assistant.db`) и переживает перезапуски.

```bash
# 1. Один раз: пакеты (сборка pydantic-core может занять 10–20 минут).
#    lxml и Pillow (нужны для конспектов и презентаций) берём готовыми из Termux:
#    собрать их через pip на телефоне без лишних библиотек не получится. ffmpeg — монтаж видео.
pkg update && pkg upgrade
pkg install python git rust binutils build-essential cloudflared termux-api python-lxml python-pillow ffmpeg
export ANDROID_API_LEVEL=$(getprop ro.build.version.sdk)

# 2. Один раз: код и зависимости. --system-site-packages — чтобы .venv видело lxml и Pillow.
git clone https://github.com/rebirthpython/elya.ai
cd elya.ai
python -m venv --system-site-packages .venv && source .venv/bin/activate
pip install -r requirements.txt

# 3. Один раз: настройки
cp .env.example .env && nano .env   # BOT_TOKEN, ALLOWED_USER_IDS, GEMINI_API_KEY

# 4. Каждый раз: запуск (сам поднимает туннель и подставляет адрес)
./termux/start.sh
```

Адрес туннеля `trycloudflare.com` меняется при каждом запуске, скрипт подставляет его
сам, а бот обновляет кнопку меню. Запускай именно через `./termux/start.sh`: обычный
`python main.py` туннель не поднимает, и Mini App не откроется (`ERR_NAME_NOT_RESOLVED`).

Обновление кода: `git pull`, затем `pip install -r requirements.txt` и снова `./termux/start.sh`.

Скрипт работает как «сторож»: если бот упал, туннель оборвался или адрес перестал отвечать
снаружи (ошибка Cloudflare 1033), он сам поднимает всё заново с новым адресом. При повторяющихся
сбоях (например, нет интернета) пауза между попытками растёт до минуты. Остановить — CTRL+C.
Открывай приложение кнопкой меню «Эля»: старые кнопки в переписке ведут на прежний адрес. Чтобы Android не убивал Termux, в настройках
приложения выбери «Без ограничений» для батареи и не смахивай Termux из недавних.

## Хостинг на Railway

Бот собирается из `Dockerfile`, рабочая папка в контейнере — `/app`, база по умолчанию —
`/app/data/assistant.db`. Диск контейнера временный: без постоянного тома история
и настройки стираются при каждом перезапуске.

Чтобы они сохранялись, подключи к сервису **Volume** с путём монтирования `/app/data`.
Менять `DATABASE_URL` не нужно. После перезапуска в логе должна быть строка
`Database: SQLite /app/data/assistant.db`.

## Безопасность

- Токены и ключи хранятся только в `.env`, который исключён из git.
- Бот отвечает только пользователям из `ALLOWED_USER_IDS` и только в личных чатах.
- Mini App пускает тех же пользователей: каждый запрос подтверждается подписью Telegram
  (`initData`), без неё API отвечает 401, чужому аккаунту — 403.
- Ответы модели в приложении выводятся как текст (без `innerHTML`), страница отдаётся
  со строгой Content-Security-Policy.
- Тексты сообщений не пишутся в логи: в логах только ID, статусы и ошибки провайдеров.
  Параметры SQL в ошибках скрыты.
- История диалога хранится целиком и сама не удаляется; стереть её можно командой `/clear`.
- Бот не выполняет код и системные команды из сообщений — в том числе в режиме кода:
  присланные файлы только читаются как текст и передаются модели.
- Результаты поиска передаются модели как данные со сторонних сайтов с запретом выполнять
  указания из них; ссылки в списке источников берутся из выдачи, а не из текста модели.
